# Mirror

A macOS menu-bar app. Click the icon to see yourself with the front camera.

## Requirements

- macOS 13 or later
- Swift 5.9 or later (Xcode Command Line Tools)

## Build

```sh
./build.sh
open Mirror.app
```

`build.sh` builds a release binary, wraps it in `Mirror.app`, and signs it ad-hoc.
